# Движение интерфейса

Анимация отвечает на вопрос «что изменилось», а не развлекает. Частота использования важнее вкуса: чем чаще действие, тем меньше движения.

## Частота

| Частота | Примеры | Движение |
| :--- | :--- | :--- |
| Сотни раз в день | набор текста, переключение табов, клавиатурные команды | нет |
| Десятки раз в день | открытие меню, наведение, отправка формы | минимальное: 100–150 мс |
| Регулярно | модалка, панель, переход между шагами | стандартное: 150–250 мс |
| Редко | онбординг, первый запуск, успех операции | выразительное: 250–400 мс |

## Длительности

- Микроотклик (hover, press): 100–150 мс.
- Стандарт (появление панели, смена состояния): 150–250 мс.
- Крупный блок или переход экрана: 250–400 мс.
- Выход короче входа: примерно 70% длительности входа.
- Дольше 400 мс — только осознанное решение, а не значение по умолчанию.

## Кривые

| Назначение | Значение |
| :--- | :--- |
| Стандартное изменение | `cubic-bezier(0.2, 0, 0, 1)` |
| Вход и появление | `cubic-bezier(0.16, 1, 0.3, 1)` |
| Выход и исчезновение | `cubic-bezier(0.4, 0, 1, 1)` |
| Жесты и удержания | пружина, а не фиксированная кривая |

`ease-in` на появлении читается как задержка: элемент «думает» перед действием.

## Свойства

- Анимируются `transform` и `opacity` — они не вызывают пересчёт раскладки.
- `width`, `height`, `top`, `left`, `margin` — запрещены; раскрытие делается `grid-template-rows`, `scale` или `clip-path`.
- `transition: all` запрещён: перечисляй свойства явно.
- `transform-origin` задаётся осознанно; у модалки и поповера — от точки вызова.
- Тень и `filter` не анимируются на больших областях.

## Поведение

- Анимация прерывается действием пользователя: повторный клик не ждёт завершения.
- Удержание и перетаскивание не имеют симметричного входа и выхода.
- Анимация не блокирует ввод и не задерживает следующее действие.
- Групповое появление — короткий stagger, не более 40–60 мс между элементами.

## Доступность

- `prefers-reduced-motion: reduce` отключает перемещение и масштаб; прозрачность допустима.
- Движение не единственный носитель смысла: состояние читается и без анимации.
- Автоплей дольше 5 секунд имеет паузу или стоп.
- Мигание и быстрые вспышки не используются.

## Angular

- Простые переходы — CSS и `@if`/`@for`; `@angular/animations` — только когда нужна координация.
- Список анимируется через `track`, иначе элементы пересоздаются и анимация рвётся.
- Частотные события (скролл, указатель) — вне зоны Angular, чтобы не запускать проверку изменений.
- `@defer` с `@placeholder` даёт появление блока без ручного флага загрузки.

## Анти-паттерны

- Одинаковая длительность у всех переходов.
- Анимация на клавиатурных действиях и в таблицах с высокой частотой.
- Появление с `scale(0)` вместо `scale(0.96)`.
- Задержка перед откликом на нажатие.
- Движение, которое нельзя прервать.
